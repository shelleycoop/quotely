# Quotely

A quiet quotes app for Android, ready to publish on Google Play.

## Run

```bash
npm start
```

Then open it in Expo Go on a phone, or press `w` for web.

## Play Store build

See `PLAY_STORE.md`. Production output is an Android App Bundle via EAS:

```bash
npx eas-cli build -p android --profile production
```

## Privacy

The in-app policy lives in Settings. The store copy is `privacy-policy.md`. Host that file publicly before you submit.
